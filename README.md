# Student Team Members Management App

## Description

This is a simple React-based web application that allows users to manage a list of team members. The app consists of two main pages:  
1. **Add Member Page**: Allows users to add new team members by providing details like name, role, and email.
2. **View Members Page**: Displays a list of all added members.

The app is built using **React** for the frontend and uses **React Router** for page navigation. All member data is stored locally in the app's state, ensuring that newly added members appear immediately when navigating between pages.

## Features

- **Add New Member**: Fill out a form with member details (name, role, email) and add them to the list.
- **View All Members**: See all added members listed with their details.

## Technologies Used

- **Frontend**: React.js
- **Routing**: React Router
- **State Management**: React useState, useEffect
- **CSS**: Basic styling for layout and buttons

## Installation

To run this app locally, follow these steps:

1. Clone the repository from GitHub.
2. Navigate to the project directory.
3. Install the required dependencies.
4. Start the development server.
5. The app will be available in your browser at `http://localhost:3000`.

## Pages

- **Home Page**: Displays the team name and links to "Add Member" and "View Members".
- **Add Member Page**: A form to add a new member.
- **View Members Page**: Displays a list of all team members.

## How to Add a Member

1. Go to the **Add Member** page.
2. Fill out the form with the member's name, role, and email.
3. Click "Add Member". The new member will be displayed in the "View Members" page immediately.

## How to View Members

1. Go to the **View Members** page.
2. A list of all team members added will be displayed.
